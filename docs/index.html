LOGKITTY

A custom 4-detent floating overlay. Monitor logs directly on top of your app. No context switching. No PC required.

./install --release ./view --source
I com.hereliesaz.logkitty.OverlayService
Always-On Context: Injects a 4-detent bottom sheet (Hidden, Peek, Half, Full) natively over the Android system. Scroll the buffer or peek at the last 4 lines without minimizing your target app.
W com.hereliesaz.logkitty.AppMonitor
Target Isolation: Intercepts UID boundaries to filter noise. Pin a dedicated tab to isolate logs strictly for the current foreground application.
I com.hereliesaz.logkitty.feature.GitHub
Dynamic Play Delivery: Mounts the `:feature:github` module on-demand. Trigger and monitor remote GitHub Actions workflows directly from the floating overlay.
E com.hereliesaz.logkitty.utils.CrashReporter
Fatal Handler: Hooks the default UncaughtExceptionHandler. Serializes local stack traces to internal storage and autonomously dispatches GitHub Issues upon recovery.
V com.hereliesaz.logkitty.FilterEngine
Local Buffer Resilience: Multi-select log levels, tag-based regex highlights, and a Prohibited list to aggressively suppress syslog noise. Extensible color schemes (Material, Pidcat, Solarized).
